# Atividade\_avançada

Este projeto tem como objetivo simular o fluxo de trabalho profissional de uma equipe de desenvolvimento de software. A aplicação foca na prática avançada de versionamento de código, abordando a criação de branches individuais, resolução proposital de conflitos de merge, revisão de código por pares via Pull Requests, gestão de melhorias por meio de Issues e publicação de versões estáveis utilizando Tags.
